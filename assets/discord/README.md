# Discord's own assets

Icons and the gg sans fonts (converted from woff2, no longer used: the app sets Gabarito and Roboto Mono) taken from Discord's web app for the user's personal use of Waffle.
They are Discord's copyrighted work under no licence: never redistribute them or ship them in a
public build.

`icons/pause.svg` and `icons/volume-off.svg` are drawn for Waffle in the same style (the speaker is
`volume-high.svg`'s), not taken from Discord.
